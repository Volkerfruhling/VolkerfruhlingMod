# GER NF議事録

planning/（世界設計）と対になる、GERのNF・イベント・国民精神・ディシジョン詳細の検討記録。

## 決定事項（2026-07 検討分）

1. βの政治ルートは議会ルートのみ。分岐点（帝国の岐路・1926年選挙・関連イベント選択肢）は
   議会側だけ選択可能にし、他方はグレーアウト＋「今後のアップデートで解放」表示。
   幹線（双頭一体の鷲〜内閣の行く末）は2列とも従来通り取得する。
2. 1926年選挙以降の政治NFは70日に統一（憲法改正の最短完了≒1929年1月末）。
3. 「29年憲法 vs 軍備 vs 産業」の三つ巴レースは日数配分から自然発生させる。人為的ロックはしない。
   憲法が開戦で中断された場合は「戦時休会」イベントで進行度をフラグ保存、戦後再開の種にする。
4. 軍事ツリーはルーデンドルフ⟷グレーナーを提言レベルで相互排他化。βでも両系統選択可。
5. 軍事ツリーの解禁ゲート：
   - 第1ゲート：総力戦研究所（軍事の根）と産業の路線分岐は「内閣の行く末」完了後
   - 第2ゲート：「嵐へ備える」以降とヴァル系はバルカン戦争勃発（vf_started_balkan_war）で解禁。
     ロック中はツールチップで条件明示、解禁時にニュースイベント1本
6. 産業ツリー簡易版（約13NF・排他1組・研究枠2）をβで実装。全ルート共通・戦時も継続。
7. 戦時ブランチは allow_branch＋ツリー再評価で出現させる（load_focus_tree不使用）。
   平時政治NFは開戦時に available で取得不可化（グレーアウト＝中断された改革の演出）。

## 第1項 国民精神の置換設計

方針：体制の成熟は「置換チェーン」で表現し、個別政策は小さく併存させる。
xlsx素通しだと安定+45%まで積み上がるため、置換で総量を管理する。

### A. 体制精神（置換チェーン・常に1つだけ）

| 段階 | 精神 | 効果 | 取得契機 |
|---|---|---|---|
| 0 | 自由主義の内閣（2年限定） | 安定+5% / PP獲得+5% | イベント「自由主義の宰相」続投選択 |
| 1 | 自由主義への道 | 安定+5% / PP獲得+10% | NF自由の理 |
| 2 | 1928年改革 | 安定+10% / PP獲得+15% / ディシジョンコスト-5% | NF大改革宣言 |
| 3 | 1929年憲法 | 安定+15% / PP獲得+25% / イデオロギー変動対抗+25% | NF憲法改正 |

- 「強化された内閣」（内閣集権：PP+10%/ディシジョンコスト-5%）と「議会主権」（国民議会の強化：
  安定+5%/イデオロギー対抗+25%）は取得時は単体精神として付与し、
  **大改革宣言の取得時に3精神を「1928年改革」1つに統合吸収**する（remove_ideas→add_ideas）。
  精神欄が改革の進行とともに整理されていく演出を兼ねる。

### B. 併存する政策精神

| 精神 | 効果 | 備考 |
|---|---|---|
| 文化的寛容（少数民族問題） | 非中核州人的+5% / 抵抗目標-10% | ボヘミア時限爆弾の平時側入力 |
| 進歩の時代（前進主義） | 月間人口+2% / 研究速度：工業+5% | |
| 失業保険制度 → 社会国家ドイツ | 安定+5%/消費財+2% → エーベルト・プラン取得で置換：安定+5%/民需建設+15%/消費財+4% | 福祉ラインも2段置換。消費財増＝福祉のコストは維持 |
| 国家奉仕（奉仕勤労団） | 訓練時間-10% / 徴兵可能人口+2% | |
| 新時代の外交（伯爵） | 外交ディシジョンコスト-25% / 関係改善効果+20% | xlsxで未定義だった中身の充当案 |

### C. 緊張精神（レースの掛け金）

| 精神 | 効果 | 消え方 |
|---|---|---|
| 未解決の遺産（帝冠領「触れない」選択） | PP獲得-5% | 対応NF完了で除去 |
| 枢密院の不在（枢密院廃止） | PP獲得+5% / 安定-10% | 憲法改正で除去（1929年憲法に吸収） |

- 「枢密院の不在」は憲法改正の2NF手前で必ず背負う設計。バランス型プレイはこの安定-10%を
  抱えたまま1929年秋の開戦を迎える＝「憲法が間に合わなかった」ことの具体的な痛み。
  戦時休会イベントの切実さに直結するため、この符号は変更しない。

### 開戦時（1929年秋）の状態比較

- 憲法達成型：1929年憲法＋社会国家＋進歩の時代など＝安定+20%超の磐石な後方。ただし軍事0。
- 憲法中断型（標準）：1928年改革＋枢密院の不在＝差し引き安定ほぼ±0、動揺を抱えた開戦。
  戦時ツリーで挽回する動機が生まれる。

## 第2項 1926年議会選挙イベント

構成：NF「1926年議会選挙」（28日＝選挙戦そのもの）完了から3連イベント。
βでは勝者はヴァイマル連合固定だが、「勝ち方」と「連合の重心」を選ばせて手応えを作る。

### イベント1「選挙戦の季節」（NF完了時）
- a. 改革の実績を静かに訴える：PP+35
- b. 組織力を総動員する：安定-3% / 民主主義支持+5% / 議会派支持+5
- c. 敵失を待つ：PP+70（民主支持ボーナスなし）

### イベント2「1926年 国民議会選挙」（7日後・開票）
選択肢＝連合の重心。いずれもヴァイマル連合勝利は共通。

| 選択肢 | 首班 | 効果 | フラグ |
|---|---|---|---|
| a. 社会民主党を軸に | フリードリヒ・エーベルト（存命設定） | 安定+5%。労働争議イベントが穏便に。ユンカーの抵抗は激化 | vf_GER_coalition_spd |
| b. 中央党との融和を | 中央党首班（マルクス的人物・要人選） | 南部州の忠誠+。帝冠領再編ディシジョンのコスト減 | vf_GER_coalition_centre |
| c. 自由主義者の内閣を | 国民自由党首班（シュトレーゼマン的人物・要人選） | PP+50 / 建設速度+5%（1年）。財界イベント有利、労働争議は荒れやすい | vf_GER_coalition_liberal |

### イベント3「新内閣の顔ぶれ」（さらに7日後）
重心に応じて首相・政治顧問プールを差し替える人事イベント。

### 設計メモ
- イベントは重心フラグを立てるだけ。NF「ヴァイマル連合の勝利」（70日）がフラグを読んで
  イデオロギー固定・与党確定・精神付与を実行（イベントとNFの分業）。
- 重心フラグは合間イベント群（ユンカーの抵抗／労働争議／帝冠領再編の各邦反応）と
  戦時「城内平和」の展開（SPD軸=労組協力、自由主義軸=財界協調）の入力になる。
- この世界のエーベルトは心労死しておらず存命。SPD軸なら首相就任し、
  NF「エーベルト・プラン」は現職首相の看板政策となる（記念事業ではない）。
- 中央党・国民自由党の首班人名は00_世界の指導者.txtとの整合を確認の上で確定する。

## 第5項 戦時ツリー簡易版（15NF）

開戦（世界大戦）で allow_branch により出現。日数は7〜21日刻み。片側消化で約160日＝開戦から
半年で一巡し、以降は継続中の軍事ツリーへ戻る。戦争疲弊分岐（講和派・スト・翻るは赤旗）は
フル版でこの下に生やす（β枠外、設計余地のみ確保）。

### 入口

| NF | 日数 | 効果 |
|---|---|---|
| 城内平和 | 7 | 精神「城内平和」（戦争協力度+10%、安定+10%）。SPD軸なら労組の争議自粛で効果+2% |
| 戦時経済体制 | 14 | 経済法を戦争経済へ変更（通常条件を無視）／ランダム3州に軍需工場+1 |

### 主導権の排他分岐（各14日）＝戦時政治の背骨

| NF | 効果 | 接続 |
|---|---|---|
| 最高軍司令部への白紙委任（軍部主導） | 精神「沈黙の独裁への道」（軍需建設+15%、PP獲得-25%） | 隠しNF「軍事独裁」の解禁条件。ルーデンドルフ系と親和 |
| 議会の戦時統制（政府主導） | 精神「議会の戦争」（安定+10%、PP+15%、戦争協力度+5%） | 文民統制と親和。戦後の憲法再開が有利になるフラグ |

- 軍部主導側（各21日）：祖国補助勤務法（徴兵可能人口+2%／工場出力+／安定-5%）
  → 軍需優先経済（3州に軍需+3）→ 宣伝戦の強化（14日、戦争協力度+10%）
- 政府主導側（各21日）：戦時社会協定（生産効率+／安定+5%、SPD軸ボーナス）
  → 戦時公債（消費財-2%）→ 議会の監視委員会（14日、戦争目的の限定＝戦後ペナルティ軽減フラグ）

### 緊急軍拡枝（主導問わず取得可・「憲法済み丸腰」型の救済）

| NF | 日数 | 効果 |
|---|---|---|
| 緊急動員令 | 7 | 歩兵装備+15,000／訓練時間-10%（1年） |
| 予備役の招集 | 14 | 師団4個スポーン（OOB）／徴兵法引き上げ |
| 兵器廠の全力稼働 | 14 | 軍需工場+2（即時） |
| 士官速成課程 | 14 | 陸軍経験値+50 |

### 終端（21日）

- 総力戦体制の完成：選んだ主導側の精神を強化版に置換（置換チェーンの戦時版）。

### 設計メモ
- 戦時休会はNFではなくイベント。開戦時に憲法改正未完なら発火、進行度をフラグ保存。
  精神「未完の憲法」等は付けない（「枢密院の不在」の安定-10%残存が既にペナルティ。二重罰にしない）。
- 戦略方針（対仏優先/対露優先）系NFは置かない（改良シュリーフェン等が軍事ツリーに既存で重複）。
  ポーランド中立侵犯もイベント側の管轄（planning参照）。
- 軍部主導→軍事独裁は「解禁」であって強制ではない。βでは議会政府と軍部の二重権力という緊張が
  生まれ、本リリースの体制転覆コンテンツへの入口になる。

## 第6項 キャラクター（β）

前提：本Modの国家元首欄は二人制。ドイツはヴィルヘルム2世（皇帝）＋カール1世（摂政）で内定済み。
したがって大宰相は元首欄ではなく**入れ替え不可の固定政治顧問**として実装する。

### 元首（固定・二人制）
- ヴィルヘルム2世（皇帝）／カール1世（摂政）

### 大宰相（固定顧問枠・プレイヤーによる解任不可、選挙/イベントでのみ交代）
| 時期 | 人物 | 特性案 |
|---|---|---|
| 開始時 | マクシミリアン・フォン・バーデン | 自由主義の調停者（PP獲得+5%、安定+5%程度） |
| 1926年選挙後（SPD軸） | フリードリヒ・エーベルト（存命設定） | 労働者の信望（安定+、戦争協力度+） |
| 同（中央党軸） | ヴィルヘルム・マルクス（仮） | 南部の融和者（南部州の忠誠+） |
| 同（自由主義軸） | グスタフ・シュトレーゼマン（仮） | 産業界の代弁者（建設+、財界イベント有利） |

※シュトレーゼマンは史実で国民自由党員のため党名との整合良好。DVP結成はこの世界では未発生。
※イベント「自由主義の宰相」で更迭を選んだ場合の後継指名ディシジョンも、この固定顧問の差し替え。

### 枢密院議長（固定顧問枠・提案）
- ゲオルク・ミヒャエリス（保守派）：弱いペナルティ混じりの特性（例：PP獲得-5%、安定+5%）で
  固定スロットを占有。**NF「枢密院廃止」でスロットごと消滅＝廃止の具体的な報酬になる**。

## 第7項 帝冠領の構造とゲーム表現・再編ディシジョン

### 正典が定める二層構造（wiki版ドイツ帝国・構成国リストより）
- 第1層：オーストリア系の通常構成国＝オーストリア大公国、シュタイアーマルク・ケルンテン・
  ザルツブルク・カルニオラ各公国、チロル伯国。バイエルン等と同格の帝国構成国だが、
  君主がすべてハプスブルク家＝摂政の本領。
- 第2層：自治領邦＝ボヘミア王国（プラハ）・クロアチア王国（ザグレブ）。エーレンタール内閣
  （1908〜10頃）が「帝国主権下で半自治、ハプスブルク家の下で独立」させた特別枠。
  クロアチアは対セルビア包囲同盟に参加するなど半ば外交主体。
- 「国家内国家」の正体：摂政が帝国内に持つ私的勢力圏（本領＋自治王国2つ）。
- 南チロルは第1層（チロル伯国）の州、イストリアは伊との共同管理中立域で独自タグ。
  いずれも帝冠領再編ディシジョンの対象外。

### HoI4上の表現（決定）
- 第1層はGER直轄州（バイエルンをタグ化しないのと同じ理屈。摂政の本領である事実は
  パワーバランス側で表現）。
- 第2層のBOH・CROは独自タグの特殊従属国。カスタム自治レベル「自治領邦」：
  工場・資源の一部を宗主が利用／軍の指揮権共有／外交は完全にベルリン委任。

### 成立の急所3点（ここが壊れると大戦設計全体が死ぬ）
1. 宣戦の連鎖保証：対CRO・対BOH宣戦＝対GER宣戦と同義になるよう自治レベル定義で強制
   （宗主の自動参戦・単独講和不可）。セルビアのクロアチア要求が「局地戦」で終わると
   世界大戦が発火しない。**SER側イベントとの結合テストをβ必須項目とする。**
2. AI従属国の事故対策：講和会議でのBOH・CRO領の処理をβから講和スクリプトで明示。
3. ボヘミア時限爆弾との整合：BOHタグの自治度＋独立傾向で忠誠を表現。蜂起＝独立戦争
   または露仏側への寝返りとして素直に書ける（タグ方式の利点）。

### ディシジョン群「オーストリア帝冠領の再編」（NF帝冠領整理案で解禁）
議会ルートの連邦化路線＝「ハプスブルクの私領を帝国議会の下の通常連邦構成国に組み替える」作業。

## 第8項 パワーバランス簡略仕様（β）

### 基本構造
- 変数3本：vf_GER_bop_kaiser（皇帝派）／vf_GER_bop_regent（摂政派）／vf_GER_bop_assembly（議会派）。
  各0〜100にクランプ。イベント・NF・ディシジョンが直接加減算する（xlsxの±5〜±20をそのまま使用）。
- 判定は相対シェア方式：議会シェア＝議会派÷（皇帝派＋摂政派＋議会派）。
  本リリースの岐路判定（議会40%以上／皇帝側50%以上／拮抗→内戦）はこのシェアで行う。
- **枢密院は第4の変数にしない**。イベント「双頭の脳髄」の選択（中立/皇帝/摂政/廃止）をフラグ化し、
  岐路判定時に支持先へ仮想+10として合算する（xlsx岐路の「皇帝派+枢密院派」条件の実装形）。
- 初期値：皇帝派35／摂政派30／議会派30、枢密院の傾き＝中立。
  （正典1925年：両君主が主導権を画策、SPD躍進中、宰相は自由主義者）

### UI（βはカスタムGUIを作らない）
- 国民精神「勢力均衡」（双頭の鷲アイコン）1枚で表現。イベント「皇帝、摂政、議会」で付与。
- 動的説明文（dynamic tooltip）に3変数の現在値と枢密院の傾きを表示。効果値は持たない
  （表示専用）。カスタムGUI化は本リリース側の課題。

### βでの挙動
- 変数の増減は全実装する（イベント9本・帝冠領ディシジョン・選挙イベント等の効果を全て反映）。
  テスターに「システムが呼吸している」ことを見せ、本リリースで閾値判定を差し込むだけにする。
- 帝国の岐路イベントは閾値判定を行わず、議会ルートのみ選択可（決定事項1の通り）。
  他選択肢はグレーアウトし、ツールチップに本来の解禁条件（シェア閾値）を予告表示する。
- 減衰・自然ドリフトはβでは入れない（イベント駆動のみ）。顧問・精神による週次ドリフトは
  本リリースの検討事項。

### 戦時
- 開戦（城内平和）で変数を凍結（フラグ vf_GER_bop_frozen）。戦時中の政治は主導権分岐
  （第5項）が代替する。戦後に凍結解除し、戦時の選択（軍部/政府主導・勝敗）で補正を加えて再開。
