## 4. 中核システムの実装

### 4-1. パワーバランス（§6-1）
変数 `vf_GER_bop_kaiser/_regent/_assembly`（0〜100クランプ）＋シェア変数。呼び出し規約: temp変数を積んで `vf_GER_change_power_balance = yes`（開戦後 `vf_GER_bop_frozen` で凍結）。表示は国民精神「勢力均衡」のdesc（`[?var]` 直接表示＋scripted locで枢密院の傾き）。岐路判定scripted_triggerは器だけ（βは議会ルート固定）。

### 4-2. 首相機構と元首欄（主宰指示 2026-08-27）
- **元首欄は二元君主で固定**: country_leader=カール1世＋Chief_Portrait変数=ヴィルヘルム2世。ヴァイマル勝利で与党socialism化した際は `add_country_leader_role`（socialism_ideology＋promote_leader）でカール1世を元首に留める
- **首相は閣僚枠**（Mod既存の `prime_minister_idea` スロット。初使用）。全員 `can_be_fired = no`＝**手動解任・交換不可**、cost=0。差し替えはスクリプトのみ: 開始時マックス → `.2`選択肢2で退陣（空位・ディシジョン解禁）→ `.14` で連合の重心に応じエーベルト/マルクス/シュトレーゼマン就任
- 人名裁定: マックス・エーベルト確定、他2名は暫定採用

### 4-3. 戦時切替（§5-2）
平時政治NF33本の `available` に `NOT = { has_global_flag = vf_greatwar_started }`（custom_trigger_tooltip付き）。戦時15本は `allow_branch = { has_global_flag = vf_greatwar_started }`。軍事・産業は開戦後も継続。戦時休会（`.10`: 憲法未完なら `vf_GER_constitution_suspended`）と対立凍結（`.11`: 岐路未解決なら `vf_GER_bop_frozen`）はトリガーイベント。

### 4-4. 日数（§5-3。裁定=現状維持で確定）
憲法改正への必要NF30本・1393日＋枢密院会議の35日 → **最短1928-12-23〜1929-01-27**（設計目標「≒1929年1月末」に机上で一致）。指示書§5-3の「4〜5ヶ月ずれる」という懸念は幹線196日と岐路遅延を勘定漏れした概算だった。

## 6. AI日程制御（選挙が1926年に間に合わない問題への対応。裁定済み）

実機でAIが産業NFへ寄り道し1926年内に選挙が完了しない問題 → **「政治NFの進行に応じたAIロック」**で対応（日数・構造・見た目は不変。プレイヤーは制限しない）。

産業13本・軍事38本の `ai_will_do` に:
- `modifier = { factor = 0 NOT = { has_completed_focus = focus_GER_pol_1926_election } }` — **選挙完了までAIは取得不可**
- `modifier = { factor = 4（軍事）/ 2（産業） has_global_flag = vf_started_balkan_war }` — バルカン戦争（1927）後は軍事20/産業16で政治20と拮抗し、**AIにも「憲法vs軍備のレース」を再現**させる

調整ノブ: 枢密院会議 `.8` の「もう無理だ」ai_chance（上げると35日短縮）、上記modifier係数。

## 7. AI軍拡（開戦時44個師団問題への対応）

**原因**: ①GERは開始時に**バニラ徴兵法・経済法を一切持たない**（他大国はhistoryで保有。RUS=limited_conscription等）②大国向けAI戦略が皆無（凍った平和で建軍動機ゼロ）③軍事NFが骨のみ。三層で対策:

1. **`_vf_GreatPowers.txt`**: GERは平時→バルカン戦争→講和後→クロアチア危機の4段階で `ai_wanted_divisions_factor` / `force_build_armies` / `added_military_to_civilian_factory_ratio` / `prepare_for_war` をエスカレーション。**RUS・FRA・ENGにも並行整備**（大戦が一方的にならないため）
2. **NFの直接軍拡**（AI任せにしない保証）: `load_oob` で歩兵強化+8／騎兵強化+4／戦時・予備役召集+12個師団。「国土防衛計画」で限定徴兵制、「緊急動員」で大規模徴兵、「戦時経済体制」→war_economy、「軍需優先経済」→総動員経済。軍需工場+4、装備備蓄（小銃3.5万・砲3千等）
3. **軍事38NFの効果を全起草**: land_doctrine系ボーナス計10回・兵科ボーナス（歩兵/砲/戦車/航空/要塞。カテゴリ名は実在確認済み）・陸軍XP・防壁idea3段置換（オストヴァル+5%→東西の防壁+10%→絶対的防御+15%）・新精神6本（シュリーフェン/前進/兵站改革/防壁3種）

**期待値**: 開戦時 初期47＋NF12＋AI建造分、開戦後+予備役12。**実機で1929年開戦時の師団数（70〜90目安）とRUS/FRA側の膨らみを要確認**。
